# Vinheria Agnello - Checkpoint 03 🍇

## Descrição do projeto

Projeto individual do Check-Point 03 da FIAP. É um sistema simples de controle de estoque de uma vinícola, feito em JavaScript.

O que foi implementado:

- Array de objetos com os vinhos (nome, tipo, safra e estoque)
- Função para **adicionar** novos vinhos (`push`)
- Função para **listar** todos os vinhos com `forEach`
- Função para mostrar vinhos com **estoque baixo** (menos de 5) com `filter`
- Função para calcular o **estoque total** com `reduce`
- Função para mostrar os **nomes em caixa alta** com `map`
- Resultados exibidos com `console.log` e `alert()`
